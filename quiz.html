Choose a .json file, drop one anywhere on this page, or paste the JSON.

File format 
{
  "title": "My exam review",
  "questions": [
    {
      "question": "What is 2 x 2?",
      "options": ["2", "4", "6", "8"],
      "answer": "B",
      "explanation": "Optional. Shown after you reveal."
    }
  ]
}
  • answer: the letter of the right option (A, B, C, D…). The exact option text also works.
  • 2 to 8 options per question; 4 is the usual.
  • explanation is optional.
  • Use `backticks` for inline code and ``` fences for code blocks, inside the strings (write line breaks as \n).
